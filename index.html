Projetos & Laboratórios

Wazuh Home Lab: SIEM & FIM

Laboratório Prático de SOC

Desafio: Construir um ambiente de monitoramento centralizado para coletar eventos de endpoints e fornecer visibilidade para análise de segurança.

Execução: Arquitetura implementada com Wazuh Manager (Ubuntu/VirtualBox) e Wazuh Agent (Windows). Configuração do módulo de File Integrity Monitoring (FIM).

Testes & Resultado: Simulação de criação e modificação de arquivos críticos. Validação prática do fluxo de operações: Endpoint → Coleta → Processamento → Alerta no Dashboard → Investigação.

Defesa de Aplicações com SafeLine WAF

Laboratório de Segurança Web

Desafio: Proteger uma aplicação web vulnerável (DVWA) contra ataques exploratórios como SQL Injection e HTTP Flood.

Execução: Criação de ambiente isolado (Ubuntu Server e Kali Linux). Configuração do SafeLine WAF atuando como proxy reverso criptografado à frente do servidor da aplicação.

Testes & Resultado: Simulação ofensiva a partir da máquina atacante. O WAF interceptou e bloqueou o tráfego abusivo, aplicando regras de limitação de taxa e negação por IP de origem.
