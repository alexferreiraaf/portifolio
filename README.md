# Portfólio de Cibersegurança - Alex Conceição Ferreira

Este é o repositório do seu site de portfólio, focado em operações de segurança, desenvolvido com HTML, CSS e JavaScript puros (sem frameworks), focado em acessibilidade, semântica e performance.

## 📂 Estrutura do Projeto

*   `index.html`: Arquivo principal com toda a estrutura e conteúdo do seu site.
*   `css/styles.css`: Arquivo de estilos (cores, layout, responsividade).
*   `js/script.js`: Interatividade (menu responsivo para celular).
*   `assets/`: Pasta para você colocar imagens (ex: uma foto sua) e o seu currículo em PDF.

## ✏️ Como Editar as Informações

Se você quiser atualizar o seu portfólio no futuro, basta abrir o arquivo `index.html` em qualquer editor de código (como o VS Code ou até mesmo o Bloco de Notas) e procurar pelo texto que deseja mudar.

### Links Importantes (Ação Necessária)

Vá até o final do arquivo `index.html`, na seção `<section id="contato">`, e substitua os placeholders pelos seus links reais:
*   Substitua `[SEU_EMAIL_AQUI]` pelo seu e-mail de contato.
*   Substitua `[SEU_LINKEDIN_AQUI]` pelo link do seu perfil no LinkedIn.
*   Substitua `[SEU_GITHUB_AQUI]` pelo link do seu perfil no GitHub.

## 🚀 Como Publicar Grátis (GitHub Pages)

Para colocar esse site online sem custos, siga os passos:

1.  Crie uma conta gratuita no [GitHub](https://github.com/).
2.  Crie um novo repositório público chamado `seu-nome.github.io` (ex: `alexferreira.github.io`).
3.  Faça o upload de todos os arquivos (`index.html`, pasta `css`, pasta `js`, etc) para dentro deste repositório.
4.  Aguarde alguns minutos e acesse o endereço `https://seu-nome.github.io` no seu navegador. O site estará no ar!

## 🎨 Personalização de Cores

Se quiser mudar os tons do site, abra o arquivo `css/styles.css`. Logo nas primeiras linhas você encontrará `:root { ... }`. Basta alterar as cores hexadecimais ali (ex: alterar a `--primary-color` para trocar a cor azul dos botões e links).
